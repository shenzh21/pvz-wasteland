# pvz:wasteland

一款使用 Godot 4.7 制作的中文塔防游戏。当前版本为 **0.4**。核弹头兵子制作。

项目中的植物、场景、界面、粒子效果、音乐和音效主要由程序实时生成。基础僵尸使用项目内绘制的分层 SVG 素材，由程序驱动关节动画；未直接收录原游戏的图片、模型、字体或音频素材。

## 当前内容

- 主线包含“前院”三关、“荒地”二十关和“芜地”三关。冒险地图使用不同的世界配色，区分荒地的暖棕黄与芜地的灰绿沙色。
- 朝天椒在芜地第一关通关后解锁，200阳光，每2.13秒抛射一次，对落点一格范围造成一次50点火焰伤害并清除寒冰减速；命中格保留0.5秒燃烧动画，不追加伤害。
- 芜地沿用荒地的种植格布局，跳过第45秒沙风，从第90秒起每45秒伤害每行最右侧植物300点，并让僵尸提速50%，持续5秒；防风草免疫沙风并保护左侧植物。
- 防风草以三倍豌豆射手频率攻击同一行左侧1格、自身格及右侧1.5格内最靠左的地面僵尸；巨人僵尸可蓄力秒杀植物，并在指定生命区间投掷小鬼。
- 南瓜头可套在植物外承受伤害；走步僵尸会蓄力投出一颗造成300伤害的篮球，投球后减速。
- 每关开始前可查看本关僵尸并选择最多八种植物。
- 已实现向日葵、豌豆射手、坚果墙、土豆地雷、樱桃炸弹、寒冰射手、红薯防卫队、鬼针草射手、仙人掌、粘液多肉、倭瓜、矮茎豌豆、聚能豆、烧烤蘑菇、南瓜头、防风草和朝天椒。
- 已实现普通、路障、铁桶、疾跑、旗帜、卡丁车小鬼、摇摆、钢盔冲锋、军迷、滑翔伞、铜头、走步和巨人僵尸。
- 音乐由程序合成，关卡外界面、前院、荒地和芜地分别使用独立的较长循环曲目；芜地曲目约74秒。
- 荒地地图的第 2、4 行不可种植；荒地行僵尸在第一大波结束前占用双倍出怪分数，之后占用 1.5 倍分数。
- 击败僵尸有8%概率掉落价值10的银币、2%概率掉落价值100的金币；通关时保留的小推车每辆折算100资金。
- 重玩任何已经完成的关卡并获胜时，都会额外得到装有10枚银币的钱袋。
- 完成前院后开放商店，可购买空投炸弹和阳光礼包，并在关卡中使用 A、S 快捷键。
- 完成荒地第14关后可在商店购买两级永久阳光铲，铲除植物时依次返还其价格的25%和50%。
- 完成荒地第20关后可购买两级“新增初始阳光”，价格10000、12000，每级永久增加100，初始阳光由150提高至250、350。
- “自动拾取”设置会同时收取落地的阳光、银币和金币。
- 设置、快捷键、关卡进度和各关出战阵容会自动保存。

## 运行

使用 Godot 4.7 打开本目录并运行 `main.tscn`，或者修改 `启动游戏.cmd` 中的 Godot 路径后双击运行。

默认操作：

- `1 2 3 4 Q W E R`：选择对应植物卡槽。
- `D`：选择铲子。
- 鼠标右键：取消当前选择。
- `P` 或 `Esc`：暂停。
- `F11`：切换全屏。

快捷键可在游戏设置中修改。暂停菜单还提供游戏倍速、音乐音量、音效音量、自动拾取阳光和钱币、血量显示等选项。

## 代码结构

- `main.gd`：场景生命周期、战斗实体更新与输入控制。
- `scripts/game_view.gd`：共享运行状态、界面与图形绘制。
- `scripts/zombie_art.gd`：基础僵尸 SVG 部件绘制与关节动画。
- `scripts/imp_art.gd`：红衣小鬼与卡丁车驾驶员，复用关节姿态并调整头身比例。
- `scripts/camo_art.gd`：军迷僵尸迷彩分层素材与匍匐、待机、啃咬动画。
- `assets/zombies/basic/preview.html`：可离线打开的造型与动作预览。
- `scripts/game_data.gd`：地图尺寸、数值、植物/僵尸图鉴及关卡配置。
- `scripts/wave_planner.gd`：波次预算和僵尸组合生成。
- `scripts/persistence.gd`：设置、快捷键、主线进度及阵容存档。
- `scripts/audio_synth.gd`：程序化音乐与音效波形生成。
- `export_presets.cfg`：Windows x64 发布构建配置。

新增植物、僵尸或关卡时，应先在 `game_data.gd` 添加定义；波次平衡、存档格式和音频生成分别在对应模块中维护，避免继续向主场景脚本堆叠无关职责。

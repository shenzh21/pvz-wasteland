# 红衣小鬼

参考用户提供的小鬼造型，使用大圆头、红色短袖、浅色内衫和短四肢。眼睛保持正视镜头，无耳朵，牙齿和下颌方向沿用已确认的基础造型。

parts/ 保留 240 × 360 共用画布；imp_art.gd 对颈部以下部件做围绕 (132,145) 的 (1.08,0.64) 比例调整。头与下颌独立运动，完整小鬼的世界锚点 (132,194)，比例 0.40。不要单独裁剪部件透明边界。

已接入步行小鬼与卡丁车驾驶员。车身遮挡驾驶员下半身。

验证：运行 tools/check_zombie_art.tscn 查看普通僵尸比例参考、小鬼行走、啃咬、冰冻与卡丁车；添加 --prepare-art-check 检查选卡右侧僵尸可见性并截图。

选卡修复：GameView 记录当前画面偏移，部件绘制先乘父级变换，完成后恢复父级变换，避免覆盖选卡摄像机和平时的画面震动。

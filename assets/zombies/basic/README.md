# 基础僵尸矢量素材

直接打开 preview.html 可查看走路、啃咬、断臂与拆件。页面不依赖本地服务器或外部资源。

zombie.svg 是完整静态造型；parts/ 包含 15 个正常部件和 1 个断臂袖口。所有部件保留统一 240 × 360 透明画布，不能分别裁边，否则当前动画坐标会错位。

rig.json 记录关节坐标，scripts/zombie_art.gd 负责 Godot 正式动画，单位比例 0.46，角色锚点为 (132,210)。网页使用同样的正常速度关节公式；冰冻按钮仅为色调示意。Godot 会根据角色速度调整步频。旗帜手臂及头部装备沿用项目现有绘制逻辑；小鬼和卡丁车驾驶员使用 ../imp/ 的红衣素材；车身沿用原绘制。

source.json 保存各部件的 SVG 源片段。头部和下颌包含静态的向下 8 单位位移，让头靠近衣领。修改完整 SVG 不会自动同步部件，应更新对应源片段并重新导出。

原版参考用于造型研究，非官方同人素材。
